# Файл настроек OpenSchool (`.cfg`)

Один и тот же файл читают и пишут приложение для **Linux**, **Windows** и **Android** (и любое будущее). Он переносит внешний вид и
некоторые настройки, но никогда не содержит учётных данных, оценок, расписания или отметок «сделано».

## Контейнер

ZIP-архив. Для чтения важны только два имени записей, всё остальное игнорируется:

| Запись | Обязательна | Что внутри |
|---|---|---|
| `config.json` | да | UTF-8 JSON, не больше **64 КБ**, ровно одна запись с таким именем |
| `background.<ext>` | нет | картинка или видео фона, не больше одной; расширение из списка ниже |

Расширения: картинки `png jpg jpeg webp gif avif`, видео `mp4 webm`. Расширение подсказка: тип определяется по содержимому.
Записи в подпапках (`sub/config.json`), с `..`, с другими именами игнорируются. Размеры проверяются по факту чтения, а не по заголовку архива.
Лимиты: десктоп принимает файл фона до 300 МБ, телефон до 20 МБ (больший файл отклоняется, остальные настройки применяются).
Видео умеет показывать только десктоп; телефон видео пропускает и оставляет прежний фон.

## `config.json`

Все поля, кроме `format`, необязательны. Неизвестные поля и значения вне допустимого набора **молча пропускаются** (поле остаётся как было).
Читающая сторона не доверяет ничего: каждое значение проверяется.

```json
{
  "format": "openschool-config",
  "version": 1,
  "style": "classic",
  "scheme": "system",
  "accent": "blue",
  "zoom": 1.15,
  "icon": "graphite",
  "bg": { "mode": "media", "kind": "image", "color": "#E2E8F0", "a": "#FF9966", "b": "#FF5E62", "angle": 160, "dim": 35, "blur": 0 },
  "notifications": { "marks": true, "homework": true, "absences": false, "changes": true, "interval_min": 15, "detail": true, "quiet": { "on": false, "from": "22:00", "to": "07:00" }, "evening": { "on": true, "at": "19:00", "tests": true } },
  "network": { "mode": "auto" }
}
```

| Поле | Допустимо | Заметки |
|---|---|---|
| `format` | строка `openschool-config` | иначе файл отклоняется |
| `version` | `1` | пока одна версия; новые поля добавляются без смены номера |
| `style` | `classic`, `terminal`, `sunrise` | |
| `scheme` | `system`, `light`, `dark` | у `terminal` всегда тёмная |
| `accent` | `default`, `blue`, `teal`, `green`, `amber`, `red`, `pink`, `purple` или `#RRGGBB` | |
| `zoom` | `0.85`, `1`, `1.15`, `1.3`, `1.5` | пишется как `1.3` (не `1.2999999…`); читается с допуском 0,001 |
| `icon` | `graphite`, `ink`, `night`, `paper`, `dusk`, `indigo`, `dawn`, `ring`, `disc`, `spark` | иконка приложения; `disc` и `spark` применяются только в режиме разработчика (без него вместо них иконка по умолчанию, а выбор остаётся в файле) |
| `bg.mode` | `default`, `solid`, `gradient`, `media` | `media` без файла в архиве и без сохранённого файла становится `default` |
| `bg.kind` | `image`, `video` | только подсказка |
| `bg.color`, `bg.a`, `bg.b` | `#RRGGBB` | |
| `bg.angle` | 0..360 | |
| `bg.name` | строка | необязательна, только подпись выбранного файла (пишет десктоп); читающие её пропускают |
| `bg.dim` | 0..80 (%) | затемнение картинки |
| `bg.blur` | 0..20 | размытие картинки |
| `notifications.marks`, `.homework`, `.absences`, `.detail` | `true` / `false` | |
| `notifications.changes` | `true` / `false` | «Замены»: урок на ближайшие дни заменён, отменён, добавлен, перенесён или сменил кабинет (необязательное, по умолчанию включено) |
| `notifications.interval_min` | `5`, `15`, `30`, `60` | платформа берёт ближайшее из того, что умеет (Android: 15, 30, 60) |
| `notifications.quiet.on` | `true` / `false` | «Не беспокоить ночью»: в тихие часы уведомления не всплывают (проверка идёт, новое видно в ленте) |
| `notifications.quiet.from`, `.to` | `"HH:MM"`, 00:00..23:59 | начало (входит) и конец (не входит); может переходить через полночь; одинаковые — тихих часов нет |
| `notifications.evening.on` | `true` / `false` | «Вечерняя сводка» о следующем учебном дне (необязательное) |
| `notifications.evening.at` | `"HH:MM"`, 00:00..23:59 | время сводки |
| `notifications.evening.tests` | `true` / `false` | называть контрольные следующего дня (без сводки — отдельным уведомлением) |
| `network.mode` | `auto`, `direct`, `system` | |

Не переносится (зависит от устройства): «сворачивать в трей», «текущий урок в шторке» / в заголовке окна, правки режима разработчика, масштаб системы, пути к файлам.

## Правила совместимости

1. Писать можно только перечисленное; читать нужно терпимо.
2. Новые необязательные поля добавляются в версию 1 без смены `version`; старые приложения их пропускают.
3. Любое поле, которого платформа не умеет, пропускается, а не считается ошибкой.
4. Общие тестовые файлы лежат в `docs/cfg/fixtures/` (`from-desktop.cfg` и `from-android.cfg` записаны самими приложениями: если формат меняется, их нужно пересоздать) (копии в тестах каждого приложения; их контрольные суммы в `SHA256SUMS`).
   Все приложения обязаны читать их одинаково; `make_fixtures.py` их генерирует.
